# AiOS
## 7-dňový To-Do Command Center

**Ako používať:** každý deň dokonči úlohy v poradí. Nepreskakuj na produkčný vývoj, kým nemáš rozhovory a potvrdený problém. Zaškrtni úlohu až vtedy, keď existuje uvedený výstup.

---

## Denný pracovný rytmus

- **Business Model:** 90–120 minút. Kontakty, správy, rozhovory a ponuky.
- **Personal Brand:** 30–60 minút. Video, prototyp, príspevok alebo dokumentácia.
- **Deep Work:** 120–180 minút. Audit, blueprint, dashboard alebo SOP.
- **Kontrola:** 15 minút. Pipeline, čísla, ďalšie kroky.

---

# DEŇ 1 — Zúženie a ponuka

## Cieľ dňa
Vybrať jeden segment, jeden problém, jedno KPI a jeden prvý produkt.

### Úlohy v poradí

- [ ] Vyber segment: autoservisy / renovácie nábytku / penzióny.
- [ ] Napíš, prečo má tento segment prístup k tebe alebo prečo ho vieš osloviť.
- [ ] Vyber jeden proces: prijatie dopytu / získanie chýbajúcich údajov / follow-up / rezervácie.
- [ ] Napíš súčasný problém v jednej vete.
- [ ] Vyber jedno hlavné KPI.
- [ ] Pomenuj prvý AI OS modul.
- [ ] Napíš, čo AI pripravuje.
- [ ] Napíš, čo musí schváliť človek.
- [ ] Stanov cenu AI Infrastructure Audit.
- [ ] Vytvor jednu vetu ponuky.

### Pracovná karta

```text
Segment:
Produkt:
Proces:
Súčasný problém:
Hlavné KPI:
Čo robí AI:
Čo schvaľuje človek:
Cena auditu:
CTA:
```

### Výstup dňa
Jedna strana s jasnou ponukou a vybraným segmentom.

### Go / Stop / Adjust

- **Go:** vieš vysvetliť produkt do 30 sekúnd.
- **Adjust:** riešiš viac než jeden proces alebo KPI.
- **Stop:** chceš začať vývojom bez rozhovoru s klientom.

# DEŇ 2 — Prototyp a audit

## Cieľ dňa
Vytvoriť obrazovku, ktorú klient pochopí, a pripraviť 20-minútový audit.

### Úlohy v poradí

- [ ] Nakresli horný panel s tromi KPI.

- [ ] Zobraz chýbajúce údaje.

- [ ] Pridaj tlačidlo ľudského schválenia.

- [ ] Priprav 10 auditných otázok.

- [ ] Dohodni, aký výsledok by audit mal klientovi priniesť.

- [ ] Čo prišlo?

| Odpovede | zmerať |  |

| Ponuky | 1–2 |  |
| Zaplatené audity | minimálne 1 ideálne |  |
| Najlepší segment | vybrať |  |

## Rozhodovací strom

- Ak nemáš odpovede, uprav personalizáciu a prvú otázku.
- Ak máš odpovede, ale nie rozhovory, zjednoduš CTA.
- Ak máš rozhovory, ale nie ponuky, problém nie je dosť bolestivý alebo audit nie je jasný.
- Ak máš ponuky, ale nie platby, uprav rozsah, dôkaz hodnoty a riziko pre klienta.
- Ak máš zaplatený audit, prioritne dodaj výsledok a získaj referenciu.
- Ak jeden segment jasne vyhráva, na ďalších 14 dní zúž marketing naň.
