# Universal AI Skills Library (Master Hub)

This repository is a master skills library containing 316 specialized skills. Each skill encapsulates focused domain expertise, workflows, and bundled resources located in `./skills/<skill-name>/`.

---

## 🧭 Skill Discovery and Execution

When handling a task that matches any specialized skill in this collection:
1. Identify the relevant skill in the directory `./skills/<skill-name>/`.
2. Read its dedicated `./skills/<skill-name>/SKILL.md` file for step-by-step instructions.
3. Access any bundled reference documents in `./skills/<skill-name>/references/` or helper scripts in `./skills/<skill-name>/scripts/`.

## 🗂️ Major Skill Categories

### 1. Document & Office Automation
- **`xlsx` / `xlsx-processing-openai`**: Advanced spreadsheet creation, formulas, data validation, and styling.
- **`docx` / `word-editor`**: Word document generation, redlining, track changes, bookmarks, tables, and styling.
- **`pptx`**: PowerPoint slide decks, layout design, typography, and corporate templates.
- **`pdf`**: PDF inspection, extraction, form filling, and page manipulation.

### 2. Software Engineering, MCP & Tooling
- **`mcp-builder`**: Building custom Model Context Protocol servers and tool integrations.
- **`web-artifacts-builder`**: Building rich web artifacts, React/Tailwind/Shadcn components.
- **`webapp-testing`**: Headless browser automation, element inspection, and console verification.
- **`frontend-design`**: Premium UI design, micro-animations, typography, and design tokens.
- **`elysia-framework-patterns`**: High-performance backend development with ElysiaJS and Bun.

### 3. AiOS Systems & Workflow Orchestration
- **`workflow-composer`**: Autonomous multi-agent pipeline planning and execution.
- **`3d-brain`**: Interactive 3D knowledge visualization and concept mapping.
- **`skill-creator`**: Authoring, testing, and packaging new agent skills.

### 4. Regulatory, Privacy & Legal Governance (250+ Skills)
- **AI Regulation**: EU AI Act classifiers (`eu-ai-act-system-classifier`, `eu-ai-act-high-risk-classifier`), NIST AI RMF, and GPAI Code of Practice.
- **Contract Analysis**: NDA review (`nda-reviewer`), due diligence gating (`due-diligence-gate`), tech contract negotiation (`tech-contract-negotiator`).
- **Data Privacy**: GDPR compliance (`gdpr-compliance`), DPIA sentinel (`dpia-sentinel`), Privacy policies (`privacy-policy-generator`).
- **Cybersecurity & Compliance**: DORA (`dora`), NIS2 (`nis2-navigator`), ISO 27001/42001, SOC 2, HIPAA, PCI-DSS.
